Introducción a HTML y CSS

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. CSS (Cascading Style Sheets) se utiliza para diseñar y maquetar páginas web. Juntos, forman la base del desarrollo web.

¿Qué es HTML?

HTML es un lenguaje de marcado que estructura el contenido en la web. Utiliza etiquetas para definir elementos como títulos, párrafos, enlaces e imágenes.
